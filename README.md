# GitHub Pages Template

Минимальный статический шаблон для GitHub Pages.

## Структура

- `index.html` — главный HTML
- `assets/css/style.css` — стили
- `assets/js/main.js` — скрипты
- `assets/img/` — изображения

## Как использовать

1. Замените контент в `index.html`.
2. Обновите стили в `assets/css/style.css`.
3. Добавьте изображения в `assets/img/`.
4. Включите GitHub Pages в настройках репозитория.
