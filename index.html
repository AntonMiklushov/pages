GitHub Pages

Стартовый шаблон для статического сайта

Минимальная структура проекта с CSS и JS. Готово для деплоя на GitHub Pages.

Документация

Структура

HTML в корне, стили в assets/css, скрипты в assets/js, медиа в assets/img.

Настройка

Замените тексты, добавьте секции и подключите свои файлы.

Деплой

Пуш в репозиторий и включение GitHub Pages в настройках.
